## 一句话结论

**13 个部位里 10 个部位的 BIS 两流派完全一致**，只有 3 个部位（背部 / 手部 / 腿部）存在攻防取舍。

所以：**先用同一套 BIS 打底，再针对这 3 个部位按场景换装。**

## 双流派对照

| 流派 | r | 取向 | 适用场景 |
|---|---:|---|---|
| **乌龟流** | **0.25** | 生存优先，仇恨仅保留 1/4 | 高伤害环境、开荒、主坦 |
| **均衡流** | **1.0** | 攻防兼顾 | 常规副本、贡献输出 |

```
最终权重 = 仇恨权重 × r + 生存权重
```

**乌龟流的核心逻辑**：抗住就是最大的贡献。护甲、耐力、躲闪给满权重，命中/暴击/力量只保留 25%。

**均衡流的核心逻辑**：Forever 里武器 DPS 直接计入，输出属性不该浪费。命中/暴击/精准全额计分，用伤害换仇恨。

**背部：监护披风 vs 坚毅披风**

- 乌龟流选 **监护披风（5.23）** —— 生存向属性占优
- 均衡流选 **坚毅披风（5.73）** —— 差距仅 0.50 分，两件都是蓝装，入手难度接近
- 💡 **建议**：主坦场合用监护披风，常规刷本用坚毅披风，差别不大

**手部：精锐勇士的龙皮手套 vs 丛林守护者手甲**

- 均衡流选 **丛林守护者手甲（9.50）** —— 制皮制造，输出属性满
- 差距 **2.05 分**，是三处分歧里最大的一处
- 💡 **建议**：这是最值得准备两套的部位。手甲配方由海加尔山「艾萨拉·夜甸」出售，做一件成本不高

**腿部：精锐将军的龙皮护腿 vs 将军的龙皮护腿**

- 注意是**同套装的两个版本**（精锐 / 非精锐），不是两件不同的装备

- 💡 **建议**：军衔够就都拿，哪个流派都能用；军衔紧张时按主玩法选

## ⚠️ 重要局限：特效不计入

**本表只计算静态属性，Use / Proc 类特效不计分。**

| 特效类型 | 是否计入 | 例子 |
|---|---|---|
| **数值型特效** | ✅ 计入 | `+60 攻击强度`、`躲闪几率提高 1%`、`防御提高 5` |
| Use 使用特效 | ❌ 不计 | `使用：护甲提高 520 点，持续 20 秒` |
| Proc 触发特效 | ❌ 不计 | `有 1% 几率获得额外攻击` |
| 条件型特效 | ❌ 不计 | `在山地区域时移动速度提高 2%` |
| 法术系特效 | ❌ 不计 | `提高法术伤害 100 点`（对熊T 无收益）|
| 套装效果 | ❌ 不计 | 需集齐才生效，不计入单件评分 |
| 抗性 | ❌ 不计 | 火/冰/自然/暗影/奥术抗性一律 0 分 |

### 典型的「分数失真」案例

| 装备 | 属性分 | 特效 | 实战价值 |
|---|---:|---|---|
| 浓烟山脉之心（饰品）| 0.00 | `使用：护甲提高 520 点，持续 20 秒` | **熊T 爆发减伤核心** |
| 生命石（饰品）| 0.00 | `使用：恢复 640–960 生命值` | 应急回血 |

**饰品位尤其要人工检查** —— 属性分只是初筛，实战特效可能是决定性的。

## Forever 熊T 机制改动

### 1. 武器 DPS 生效

经典怀旧服里熊形态武器只看属性不看 DPS，**Forever 里 DPS 直接计入**。

```
武器 DPS 权重 = 0.0339 × 14 = 0.4746（攻击权重）
```

一把 77.4 DPS 的双手武器，仅 DPS 一项在均衡流就有 **36.8 分**，乌龟流是 9.2 分。这是双手武器均衡流基准（34.46）远高于乌龟流（14.51）的原因。

### 2. 防御等级额外增加护甲

```
防御等级权重 = 旧防等 0.0564 + 护甲权重 0.0221 × 2 = 0.1006
```

注意是**加护甲权重×2**，不是防等权重×2。

### 3. 新增精准属性（双路径计分）

Forever 引入精准，正面攻击每 1% 精准降低目标 1% 躲闪 + 1% 招架。

本表采用**仇恨 + 生存双路径**：

```
仇恨向：精准 = 命中 × 2 = 2.5124
生存向：精准 = 0.89
  推导：典型 5 人本 BOSS（招架 5%、攻速 2.0s、单次 800 伤、招架加速 40%）
       每 1% 精准 → 减少 0.005 次招架/秒 → DTPS 降低约 1.6
       战斗 60 秒 → 减少 96 伤害 → 折合 7.4 耐力当量 → 0.89 分

乌龟流 = 2.5124 × 0.25 + 0.89 = 1.5181
均衡流 = 2.5124 × 1.00 + 0.89 = 3.4024
```

> 🚩 **存疑标注**：ForeverDB 官方认为精准应 < 1.0× 命中。当前库内单件最多 2% 精准，即使权重下调，影响也仅 1–2 分，不改变 BIS 结论。

### 4. 额外护甲（绿甲）享受 ×4.6

```
装备显示 +150点护甲 → 熊形态实际获得 150 × 4.6 = 690 护甲
```

绿甲同样计入评分（权重与基础护甲相同），这让带绿甲的坦克装价值大幅提升。

> ⚠️ **注意区分**：装备自带的 `+80 / +100 点护甲` 属于**基础属性**，不是随机附魔，必须计入评分并保留显示。

### 5. 野性战斗技能

```
野性技能权重 = 0.04 × 1.2562（命中）+ 0.02 × 0.9108（暴击）= 0.0685
```

每 +1 野性战斗技能 = 命中 +0.04% + 暴击 +0.02%。

> 注：顺劈斩受 `min(skill, 300)` 限制，满级基础技能已满 300 时无收益，因此按「情形A」取 0.0685。

## 已知问题与后续

- [ ] **Use / Proc 特效**：仍不计入评分，饰品位需人工判断
- [ ] **套装效果评分**：当前不计入，若集齐套装需手工加权
- [ ] 🚩 **精准权重**：当前仇恨 2.0× 命中，ForeverDB 认为应 < 1.0×，待校准
- [ ] **出处补全**：部分物品出处为推断值，可靠性有限
- [ ] **团本装备**：当前已过滤，待 12 月 9 日团本开放后可解禁
- [ ] **招架属性**：3 件「招架 +X%」装备（魔化战锤 12776、疯狂长矛 13056、巨型长刃 18502）尚未确定权重
- [ ] **交叉验证**：可与 Wowhead 官方 Feral Druid DPS BiS 指南对表，找出模型盲区

## 免责声明

本项目为个人研究性质的装备评分工具，权重体系基于自制内部模型 + Forever 机制推导，**不代表官方数值，也不保证适用于所有战斗场景**。

评分仅供装备取舍参考。实际配装请结合：

- 具体 BOSS 机制（抗性需求、物理/法术伤害比例）
- 团队配置（是否有其他坦克分担）
- 个人手法与习惯

**装备是死的，人是活的。**
