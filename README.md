## 什么是「乌龟流」

本项目的评分体系把每件装备拆成**仇恨**与**生存**两套权重，再用系数 `r` 加权合成。

```
最终权重 = 仇恨权重 × r + 生存权重
```

| 流派 | r | 取向 | 适用场景 |
|---|---:|---|---|
| **乌龟流** | **0.25** | 生存优先，仇恨仅保留 1/4 | 高伤害环境、开荒、主坦 |
| 均衡流 | 1.0 | 攻防兼顾 | 常规副本、贡献输出 |

**乌龟流的核心逻辑**：抗住就是最大的贡献。护甲、耐力、躲闪给满权重，命中/暴击/力量只保留 25%，避免为输出牺牲生存。

### 乌龟流的三个特点

1. **护甲与耐力权重全保留** —— 护甲 0.0221（绿甲同样计入）、耐力 0.1209，是所有属性里最高的两项
2. **躲闪权重 0.4702 全部保留** —— 每 1% 躲闪 = 0.47 分，价值远超命中（0.31）
3. **力量/命中/暴击只剩 25%** —— 输出属性大幅贬值，避免为了 DPS 牺牲生存

> **额外护甲（绿甲）在乌龟流的特别地位**：`+150点护甲` 折合 3.32 分，相当于 27 点耐力。带绿甲的坦克装在乌龟流里往往排名远高于同 ilvl 输出装。

## ⚠️ 重要局限：特效不计入

**本表只计算静态属性，Use / Proc 类特效不计分。**

| 特效类型 | 是否计入 | 例子 |
|---|---|---|
| **数值型特效** | ✅ 计入 | `+60 攻击强度`、`躲闪几率提高 1%`、`防御提高 5` |
| Use 使用特效 | ❌ 不计 | `使用：护甲提高 520 点，持续 20 秒` |
| Proc 触发特效 | ❌ 不计 | `有 1% 几率获得额外攻击` |
| 条件型特效 | ❌ 不计 | `在山地区域时移动速度提高 2%` |
| 法术系特效 | ❌ 不计 | `提高法术伤害 100 点`（对熊T 无收益）|
| 套装效果 | ❌ 不计 | 需集齐才生效 |

### 典型的「分数失真」案例

| 装备 | 属性分 | 特效 | 实战价值 |
|---|---:|---|---|
| 浓烟山脉之心（饰品）| 0.00 | `使用：护甲提高 520 点，持续 20 秒` | **熊T 爆发减伤核心** |
| 生命石（饰品）| 0.00 | `使用：恢复 640–960 生命值` | 应急回血 |

**饰品位尤其要人工检查** —— 属性分只是初筛，实战特效可能是决定性的。

## Forever 熊T 机制改动

这四项机制让 Forever 的装备评价与经典怀旧服明显不同：

### 1. 武器 DPS 生效

经典怀旧服里熊形态武器只看属性不看 DPS，**Forever 里 DPS 直接计入**。

```
武器 DPS 权重 = 0.0339 × 14 = 0.4746（攻击权重）
```

一把 77.4 DPS 的双手武器，仅 DPS 一项就有 **36.8 分**，这是双手武器分数远高于其他部位的原因。

### 2. 防御等级额外增加护甲

```
防御等级权重 = 旧防等 0.0564 + 护甲权重 0.0221 × 2 = 0.1006
```

注意是**加护甲权重×2**，不是防等权重×2。

### 3. 新增精准属性

Forever 引入精准，正面攻击每 1% 精准降低目标 1% 躲闪 + 1% 招架。

> 🚩 **存疑标注**：本表按「精准 = 命中 × 2」计算（2.5124），但 **ForeverDB 官方认为应 < 1.0×**。熊形态没有招架，只需处理躲闪，因此 2.0× 可能偏激进。
>
> 好在当前库内单件最多只有 2% 精准，即使权重下调，影响也仅 1-2 分，不改变 BIS 结论。

### 4. 额外护甲（绿甲）享受 ×4.6

```
装备显示 +150点护甲 → 熊形态实际获得 150 × 4.6 = 690 护甲
```

绿甲同样计入评分（权重与基础护甲相同），这让带绿甲的坦克装价值大幅提升。


### 5. 野性战斗技能

```
野性技能权重 = 0.04 × 1.2562（命中）+ 0.02 × 0.9108（暴击）= 0.0685
```

每 +1 野性战斗技能 = 命中 +0.04% + 暴击 +0.02%。

> 注：顺劈斩受 `min(skill, 300)` 限制，满级基础技能已满 300 时无收益，因此按「情形A」取 0.0685。

## 数据来源与校验

### 主数据源

**Wowhead Forever 接口**：

```
https://nether.wowhead.com/tooltip/item/{id}?dataEnv=16&locale=4
```

- `dataEnv=16` = Forever 版本数据（区别于正式服的 `dataEnv=1`）
- `locale=4` = 简体中文

### 数据校验

| 校验项 | 结果 |
|---|---|
| 属性核对 | **772 件 / 0 差异**（与原始 tooltip 逐字段比对）|
| 中文名覆盖 | **772 / 772（100%）** |
| 分数复算 | 全部通过 |

### 已修复的问题

| # | 问题 | 影响 |
|---|---|---|
| 1 | 脚部部位未识别（游戏文本用「脚」非「脚部」）| 漏抓 27 件靴子 |
| 2 | 套装效果被计入单件属性 | 评分虚高 |
| 3 | 额外护甲 `+N点护甲` 未参与评分 | 46 件评分偏低 |
| 4 | 「被躲闪或招架的几率降低 1%」未识别为精准 | 漏算精准属性 |
| 5 | 套装成员列表污染部位判断 | 部位错误 |
| 6 | 皮甲强制要求敏/力，误删高命中装备 | 漏 173 件 |
| 7 | Wowhead 正式服与 Forever 数据混用 | 已统一走 Forever |
| 8 | 手工翻译错误（Eye of Rend 误作「撕裂之眼」）| 已改官方译名「雷德之眼」|
| 9 | **数值型特效未计入评分** | **271 件评分偏低，已修复** |

### 数据源限制

| 项 | 情况 |
|---|---|
| 反爬限制 | `curl` 被 CloudFront 地区封锁（403），须走浏览器 |
| 批量接口 | 不存在，每次仅能查单个 ID |
| 出处字段 | 部分物品 tooltip 不含来源，需逐件查详情页 |
